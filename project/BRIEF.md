# Studio Launch

Build a creative portfolio that visitors can explore and customize. The project is fictional; the three original studies are Form & Rhythm (Type), Blue Hour (Composition), and Open Studio (Type).

## First result

A title, an introduction, three project previews, and working navigation. Start with a short plan before editing. Keep it simple enough to open as a local HTML file.

## Next changes

Improve typography and spacing. Add All, Type, and Composition filters. Add an accessible poster editor with a headline and palette controls. Save an explicitly device-local draft and export a PNG.

## Checks

- All shows 3 projects; Type shows 2; Composition shows 1.
- A saved draft survives a page reload in the same browser.
- A failed save leaves the current design intact and reports the failure.
- Export produces a 900 by 1125 pixel PNG of the current design.
- The page works at phone and desktop sizes and the editor works by keyboard.
- The page has a factual title and description, not invented rankings or testimonials.

## Boundaries

No accounts, payment collection, cloud persistence, external API keys, scraping, or publishing without approval. Do not invent credentials or claims. Ask before adding a dependency or connecting a service. Keep original assets and other working features intact. Report actual checks and limitations.
