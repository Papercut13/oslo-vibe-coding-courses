# Ask this website

Add a small help chat to the existing Studio Launch site. Use the site's own reviewed public content, not the internet.

## The three checks

1. "How do I download a poster?" finds the download instructions and a source link.
2. "Do you offer refunds?" has no matching source; say the site has no answer.
3. Change a reviewed fact, rebuild, and check that the source page and answer agree.

## Two modes

Site search works offline and shows exact source text. AI answer optionally sends the current question and selected public snippets through /api/chat to Vercel AI Gateway. It is not a local model and requires server-side credentials and usage controls.

Preserve the original portfolio features. Never put API keys or private files in browser assets. Do not enable paid AI or publish without approval.
