# Studio Launch Build Along

These are suggested workshop requests, not a transcript of how the reference was built.

## 1 Plan

Read BRIEF.md and inspect the project. Build a small creative portfolio called Studio Launch. Ask up to three questions that affect the result, then propose the first version and its checks. Do not edit yet.

## 2 First page

Build the agreed page with the three supplied project studies. Keep it responsive and keyboard accessible. No login, backend, payments, or invented claims. Open the preview and report what works.

## 3 Design

Use the supplied reference and original artwork. Improve typography, spacing, and visual hierarchy without changing the content or breaking navigation. Show desktop and phone screenshots. Ask before installing anything.

## 4 Interaction

Add All, Type, and Composition filters. Use each project's category, not its position. Make the selected state visible and accessible. Verify counts of 3, 2, and 1. Preserve the page layout.

## 5 Persistence

Save the poster headline and palette on this device only. Restore a valid draft after reload. Handle invalid saved data and failed writes without losing the current design. Report the storage limitations.

## 6 Review

Check the page on desktop and at 390 pixels wide. Try keyboard navigation, every filter, the editor, save, and export. For a failure, show how to reproduce it and propose the smallest repair. Keep passing checks intact.

## 7 SEO

Audit the page's title, description, visible headings, and descriptive links. Use only the actual project facts. Propose improvements, show the resulting HTML, and rerun the page checks. Do not invent reviews or promise rankings.

## 8 Release

Inspect the repository and existing test commands. Propose a small branch, automated checks, and a preview deployment. Keep secrets out of files and logs. Explain what becomes public. Do not publish or merge until approved.

## 9 Your feature

Add a bookmark toggle for each project and a Saved filter. Save only on this device. Test saving, unsaving, reload, an empty Saved view, and unavailable storage. Preserve the original filters and poster editor. Plan first, then implement one small change.

## Context for the next session

Write a concise handoff: what works, which files matter, what was checked, and one next task. Do not include passwords or secrets. The completed reference deliberately does not include the bookmark exercise.
